# MotoAmici

App per motociclisti per trovare compagni di giro. Questo repository parte con un **prototipo GPS usa-e-getta** che verifica il tracciamento in background su Android (Samsung, Xiaomi).

- Progetto: `docs/superpowers/specs/2026-11-22-moto-app-design.md`
- Piano in corso: `docs/superpowers/plans/2026-11-22-prototipo-gps.md`

## Comandi
- `npm test`: prove della logica (Jest)
- `npm run typecheck`: controllo dei tipi

Copia `.env.example` in `.env` e inserisci URL e chiave anon di Supabase (vedi `docs/setup-supabase.md`).
